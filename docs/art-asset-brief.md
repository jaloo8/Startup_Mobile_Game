# VENTURE — Visual Asset Creative Brief

**Studio:** Water Hazard Studios
**Game:** Venture — a premium mobile startup simulation game
**Price:** $2.99 (one-time, no ads)
**Platforms:** iOS and Android
**Art style:** Dark navy UI, pixel art characters, retro-modern aesthetic
**Color palette:** Deep navy (#0F172A), blue (#2563EB), white text (#F8FAFC), accent gold (#F59E0B), green (#22C55E), red (#EF4444)
**Mood:** Professional but playful. Think "what if a Bloomberg terminal was a cozy indie game."

---

## How to Use This File

Copy each prompt below into **claude.ai** (or ChatGPT/Midjourney/etc.) one at a time. Each prompt is self-contained with exact dimensions, style, and content. Save each result and place it in `assets/branding/` in the project.

## ASSET 1: App Store Icon
**File:** `app_icon_1024.png`
**Size:** 1024 x 1024 pixels
**Required by:** Apple App Store, Google Play Store

### Prompt:
```
Create a square app icon (1024x1024) for a mobile game called "Venture" by Water Hazard Studios.

The icon should feature:
- A pixel-art style golf flag (red pennant) on a thin silver pole, planted in stylized blue pixel-art water waves
- A small white golf ball half-submerged in the water near the flag
- Dark navy background (#0F172A to #1E293B gradient)
- The water should use stepped/blocky pixel-art wave shapes in shades of blue (#2563EB, #3B82F6, #60A5FA)
- Small "WH" pixel letters on the red flag (optional, only if it reads clearly at small sizes)
- Clean, bold, readable at 60x60px (phone home screen size)
- Rounded corners (iOS will clip to superellipse automatically, so fill the full square)
- No text outside the flag — the icon should work without any title text
- Style: retro pixel art meets modern flat design. Think Crossy Road meets Monument Valley icon quality.
```

### Store Submission Requirements

**Apple App Store (required):**
- App icon: 1024x1024 PNG, no alpha, no rounded corners (Apple clips automatically)
- Screenshots: minimum 3, recommended 6, for each device size:
  - 6.7" (1290x2796) — iPhone 15 Pro Max ← generate these
  - 6.5" (1284x2778) — iPhone 14 Plus (can reuse 6.7")
  - 5.5" (1242x2208) — iPhone 8 Plus (scale down from 6.7")
  - iPad Pro 12.9" (2048x2732) — if targeting iPad

**Google Play (required):**
- App icon: 512x512 PNG
- Feature graphic: 1024x500 PNG (REQUIRED)
- Screenshots: minimum 2, recommended 8
- Phone screenshots: 16:9 or 9:16, min 320px, max 3840px

### Style Notes for Consistency

When generating, always include these notes to keep everything cohesive:
- Dark navy backgrounds (#0F172A), never white or light gray
- Pixel art characters are chunky and charming (think 14x20 pixels scaled up)
- UI mockups should show dark-themed cards with subtle borders
- Accent colors: blue (#2563EB), gold (#F59E0B), green (#22C55E), red (#EF4444)
- Font style: monospace or clean sans-serif, always white on dark
- Overall vibe: "cozy Bloomberg terminal" — data-rich but inviting
- This is a PREMIUM game — no ads, no gacha, no energy timers. Show that quality.
